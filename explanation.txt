AI Research Assistant - Code Explanation

Project Overview

The AI Research Assistant is a Python-based application that performs real-time web research using the Tavily API and generates summarized information using Large Language Models through the Groq API. The project also includes a graphical user interface built using Tkinter for improved user interaction.

The main objective of this project is to automate the process of searching information from the internet and generating concise AI-powered summaries.

---

Project Workflow

User Input
    ↓
Tkinter GUI
    ↓
Tavily Search API
    ↓
Collect Search Results
    ↓
Groq LLM Summarization
    ↓
Display AI Summary

Explanation of Each File

---

1. main.py

Purpose

The "main.py" file acts as the main controller of the project. It accepts user input, performs web search using Tavily API, and generates summaries using Groq LLM.

---

User Input

topic = input("Enter research topic: ")

This line accepts the research topic from the user.

---

Calling Search Function

results = search_topic(topic)

This function calls the search module to retrieve web search results.

---

Calling Summarizer Function

summary = summarize(results, topic)

This sends the collected search results to the AI model for summarization.

---

2. search.py

Purpose

The "search.py" file handles web searching functionality using the Tavily API.

---

Importing Required Libraries

from tavily import TavilyClient
from dotenv import load_dotenv
import os

- "TavilyClient" is used for accessing Tavily API.
- "load_dotenv()" loads environment variables.
- "os" is used for reading API keys.

---

Loading Environment Variables

load_dotenv()

Loads API keys from the ".env" file.

---

Creating Tavily Client

client = TavilyClient(
    api_key=os.getenv("TAVILY_API_KEY")
)

This authenticates the Tavily API.

---

Search Function

def search_topic(query):

This function performs the web search operation.

---

Sending Search Request

response = client.search(
    query=query,
    search_depth="advanced",
    max_results=5
)

- "query" contains the user topic.
- "search_depth="advanced"" improves search quality.
- "max_results=5" limits the output to five results.

---

Returning Results

return response["results"]

Returns search results to the main program.

---

3. summarizer.py

Purpose

The "summarizer.py" file is responsible for generating AI summaries using Groq LLM.

---

Importing Libraries

from groq import Groq
from dotenv import load_dotenv
import os

These libraries help connect the application to the Groq API.

---

Creating Groq Client

client = Groq(
    api_key=os.getenv("GROQ_API_KEY")
)

Authenticates the Groq API using the API key stored in ".env".

---

Combining Search Results

combined_text += f"""
Title: {r['title']}
Content: {r['content']}
"""

This combines all retrieved search results into one large text block.

---

Prompt Creation

prompt = f"""
Topic: {topic}

Summarize the following research:
"""

This prompt instructs the AI model to summarize the collected information.

---

AI Model Request

response = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[
        {
            "role": "user",
            "content": prompt
        }
    ]
)

This sends the prompt to the Groq LLM for processing.

---

Returning Final Summary

return response.choices[0].message.content

Returns the generated AI summary.
